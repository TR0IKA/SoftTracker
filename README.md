# SoftTrack 1.3.2

Android-трекер привычек: Kotlin, Jetpack Compose, Material 3, SQLite.

## Что нового в 1.3.2
- «Путь»: объёмная 3D-дорога (плита, поперечные огни, световые столбы, бегущие огни), планеты и астероиды вокруг, больше звёзд, комета, парящие планеты, анимации завершения, лёгкая инерция при перетаскивании, камера подъезжает к выбранной планете.
- Кнопка «+» плавно сдвигается вверх, когда на пути выбрана привычка (не перекрывает кнопки карточки).
- Режим разработчика: 7 нажатий на версию в настройках. Отдельные цвета для кнопки «+», фона, карточек, панели, текста, дороги, планет и звёзд.
- Постоянная подпись APK, шаблоны привычек, свой фон, значки и фото привычек, 12 акцентов и свой цвет, темы Aurora, Nocturne и «Путь».

## Подпись
Секреты репозитория (Settings → Secrets and variables → Actions): `KEYSTORE_BASE64` (содержимое файла softtrack.jks.b64) и `KEYSTORE_PASSWORD`. Без них сборка подпишется временным ключом, и обновление поверх не поставится. `versionCode` надо увеличивать в каждой новой версии.

## Данные
- `softtrack.db`: версия 2. Миграция 1 → 2 добавляет колонки и таблицы `habit_rules`, `day_notes`, ничего не удаляет.
- Старое «ежедневно» становится «все 7 дней». Старое «несколько раз в неделю» становится Пн/Ср/Пт с целью 3 в неделю с даты обновления; прошлые дни не считаются пропусками.
- Бэкап JSON `softtrack-backup` версии 2; файлы версии 1 импортируются.

## Уведомления
Один будильник на пару «привычка + день недели», пересчёт при запуске, загрузке, смене времени и часового пояса. Android 13+: запрос `POST_NOTIFICATIONS`. Точные будильники (Android 12+) включаются в настройках; без них напоминания могут опаздывать на несколько минут.
