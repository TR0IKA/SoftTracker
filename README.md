# SoftTrack 1.2.0 Aurora

Android-трекер привычек: Kotlin, Jetpack Compose, Material 3, SQLite.

## Что нового
- Оформление Aurora (чёрный, слива, лаванда, четырёхконечные звёзды, свечение, частицы); Nocturne и Field Notes сохранены.
- Расписание для каждой привычки: выбранные дни недели и своё время напоминания на каждый день.
- Незапланированный день никогда не считается пропуском; серии, рекорды и статистика считают только запланированные дни.
- Изменение расписания действует с текущего дня, старая история не переписывается (версии правил в `habit_rules`).
- Новые экраны: Календарь, расширенная Статистика (7/30 дней, сравнение периодов, серии, рекорды), карточка привычки.
- Архив, избранное, поиск, фильтры, сортировка, заметки по дням, цель на неделю.
- Настройки эффектов (выкл / мягкие / средние / яркие, отдельный выключатель частиц) и уведомлений.

## Данные
- `softtrack.db`: версия 2. Миграция 1 → 2 добавляет колонки и таблицы `habit_rules`, `day_notes`, ничего не удаляет.
- Старое «ежедневно» становится «все 7 дней». Старое «несколько раз в неделю» становится Пн/Ср/Пт с целью 3 в неделю с даты обновления; прошлые дни не считаются пропусками.
- Бэкап JSON `softtrack-backup` версии 2; файлы версии 1 импортируются.

## Уведомления
Один будильник на пару «привычка + день недели», пересчёт при запуске, загрузке, смене времени и часового пояса. Android 13+: запрос `POST_NOTIFICATIONS`. Точные будильники (Android 12+) включаются в настройках; без них напоминания могут опаздывать на несколько минут.
