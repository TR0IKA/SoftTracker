# SoftTrack 1.1.0

Нативный Android-трекер привычек на Kotlin и Jetpack Compose.

## Дизайн
- **Nocturne** — тёмная графитово-синяя палитра, матовые поверхности, сдержанные акценты.
- **Field Notes** — тёплая бумажная палитра, редакционная типографика, прямые линии и компактная сетка.
- Переключение оформления сохраняется между запусками. Акцентный цвет настраивается отдельно.

## Возможности
- Сегодня: дата, выполнение полезных привычек, процент и прогресс.
- Привычки: список, фильтр по типу, добавление и удаление, категории, расписание и заметки.
- Наблюдение за нежелательными привычками без оценочных формулировок.
- Статистика за последние 7 дней.
- JSON-экспорт и импорт.
- Локальная SQLite-база.

## Совместимость данных
Сохранены имя базы `softtrack.db`, версия схемы SQLite `1`, таблицы `habits` и `entries`, а также формат JSON `softtrack-backup` версии `1`. При обновлении интерфейса база не пересоздаётся. Импорт резервной копии, как и раньше, заменяет текущий набор привычек и историю.

## Сборка APK через GitHub Actions
1. Загрузите всё содержимое проекта в корень репозитория GitHub.
2. Откройте вкладку **Actions**.
3. Запустите **Build SoftTrack APK** или сделайте push.
4. После успешной сборки откройте запуск workflow и скачайте artifact **SoftTrack-debug-apk**.
5. В ZIP будет `app-debug.apk`.

## Локальная сборка
Нужны JDK 17, Android SDK Platform 36 и Gradle 8.13. Выполните `gradle --no-daemon assembleDebug`.

## Примечание
Перед публикацией проверьте APK на реальном устройстве, особенно сценарии импорта/экспорта и поведение при восстановлении резервной копии.
