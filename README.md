# SoftTrack

Нативный Android-трекер привычек на Kotlin + Jetpack Compose.

## Уже реализовано в стартовой версии
- Главный экран с прогрессом за день
- Категории и стартовый набор привычек из чек-листов
- Добавление полезных и вредных привычек
- Отметка выполнения и запись события для вредной привычки
- Простая статистика за последние 7 дней
- Тёмная/светлая тема и выбор акцентного цвета
- Экспорт и импорт резервной копии JSON
- GitHub Actions для сборки debug APK

## Сборка через GitHub
1. Создай пустой репозиторий GitHub.
2. Загрузи содержимое этой папки в корень репозитория.
3. Открой вкладку **Actions**.
4. Запусти workflow **Build SoftTrack APK** или дождись автоматической сборки после push.
5. Открой завершённый запуск workflow и скачай artifact `SoftTrack-debug-apk`.
6. Внутри архива будет `app-debug.apk`.

## Локальная сборка
Нужны JDK 17, Android SDK Platform 36 и Gradle 8.13.
В корне проекта выполни:
`gradle assembleDebug`

## Важно
Это первая рабочая основа проекта. Напоминания, Android-виджет, полноценный календарь, редактирование существующих привычек, расширенная аналитика и тесты нужно добавить следующими итерациями. Перед публикацией следует протестировать импорт/экспорт и работу на реальном устройстве.
